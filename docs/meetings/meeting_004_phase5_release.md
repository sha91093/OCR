#### 2-2. Windows インストール手順書（渡辺）

**渡辺**: `docs/install_windows.md` を作成しました。対象は各部署のIT管理担当者です。

主な内容:
- システム要件（RAM 4GB以上、Python不要、インターネット不要）
- フォルダコピーによるインストール手順（`C:\Tools\` 推奨）
- 初回起動時の SmartScreen 警告対処
- OCRエンジン動作確認手順
- ndlocr-liteモデルのUSB転送・配置手順
- アンインストール・アップデート手順
- トラブルシューティング（DLL不足・OCR未認識・権限エラーなど）

**田中**: `C:\Program Files\` 以外を推奨インストール先にした理由は？

**渡辺**: `C:\Program Files\` は標準ユーザー権限だと書き込みできないことがあります。
アプリが設定やDBファイルを exeと同じフォルダに書き込む設計なので、
`C:\Tools\` のような書き込み自由なパスを推奨しています。

**佐藤**: 将来的にはユーザーディレクトリ（`%APPDATA%`）にデータを書き出す設計に
変更した方が望ましいですね。今回は既存設計を踏まえた現実的な対応として理解しました。

**渡辺**: はい、v1.0でのリファクタリング候補として記録しておきます。

#### 2-3. バージョン表示機能（佐藤）

**佐藤**: `config/settings.py` の `AppConfig.VERSION` を参照して、
ウィンドウタイトルバーとステータスバー右端にバージョン番号を表示するよう実装しました。

変更ファイル:

**木村**: ステータスバーへの表示は操作者が確認しやすくて良いですね。

起動時のログ出力はログファイルで確認でき、問題ありません。
