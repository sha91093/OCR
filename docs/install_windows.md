## 1. はじめに

### このドキュメントの目的

本手順書は、**庁内のIT管理担当者**を対象に、「OCR申請書読み取りツール」をLGWAN接続PCへインストールする手順を説明します。

### 重要な前提

- 本ツールは**Pythonのインストールが不要**です。実行ファイル（`.exe`）にPythonランタイムがすべて含まれています。
- **インターネット接続不要**で動作します。USBメモリまたは庁内ファイルサーバー経由で配布・インストールしてください。
- インストールは**フォルダのコピーのみ**です。Windowsのインストーラー（`.msi`等）は使用しません。

### OCRエンジンについて

| エンジン | 配布形態 | 追加作業 |
|---|---|---|
| **Tesseract**（標準） | exeフォルダに同梱済み | 不要 |
| **ndlocr-lite**（高精度） | 別途USBで転送が必要 | [手順5](#5-ndlocr-liteモデルの追加任意高精度化) を参照 |

通常はTesseractだけでも業務利用可能です。ndlocr-liteは縦書きや旧字体の申請書で精度が向上します。

## 2. システム要件

### 必須要件

| 項目 | 要件 |
|---|---|
| OS | Windows 10（64bit）または Windows 11 |
| CPU | Intel Core i3 以上（Celeron N4000 以上でも動作確認済み） |
| RAM | **4GB以上**（ndlocr-lite使用時も4GBで動作可） |
| ストレージ空き容量 | **500MB以上**（ndlocr-liteモデルを追加する場合は1GB以上） |

| Pythonのインストール | **不要** |
| インターネット接続 | **不要** |

| 項目 | 推奨値 |
|---|---|
| RAM | 8GB以上 |
| ストレージ空き容量 | 2GB以上 |
| 画面解像度 | 1920×1080以上 |

## 3. インストール手順

### 手順3-1. 配布パッケージの受け取り

システム担当者からUSBメモリまたは庁内ファイルサーバー経由で、以下のフォルダを受け取ってください。

```
ocr_shinseisho\                    ← このフォルダごとコピーします
├── ocr_shinseisho.exe             ← 起動ファイル
├── tesseract\                     ← Tesseract OCRエンジン（同梱済み）
│   ├── tesseract.exe
│   ├── tessdata\
│   │   ├── jpn.traineddata        ← 日本語認識モデル
│   │   ├── jpn_vert.traineddata   ← 日本語縦書き認識モデル
│   │   └── eng.traineddata        ← 英数字認識モデル
│   └── *.dll
├── config\                        ← アプリ設定ファイル
└── _internal\                     ← Pythonランタイム（変更不要）
```

> **注意:** `ocr_shinseisho.exe` だけをコピーしても動作しません。必ず**フォルダごと**コピーしてください。

### 手順3-2. インストール先フォルダの作成

PCのエクスプローラーを開き、インストール先フォルダを作成します。

**推奨インストール先:**

```
C:\Tools\ocr_shinseisho\
```

> **フォルダの作成方法:**
> 1. エクスプローラーで `C:\` を開く
> 2. 右クリック → 「新規作成」→「フォルダー」
> 3. フォルダ名を `Tools` と入力してEnter
> 4. 作成した `Tools` フォルダを開く

> **注意:** `C:\Program Files\` 以下にはインストールしないでください。書き込み権限の関係でアプリが正常に動作しない場合があります。

### 手順3-3. フォルダのコピー

USBメモリまたはファイルサーバーから `ocr_shinseisho` フォルダを `C:\Tools\` にコピーします。

**コピー手順:**
1. USBメモリまたはファイルサーバー上の `ocr_shinseisho` フォルダを右クリック
2. 「コピー」を選択
3. `C:\Tools\` を開く
4. 右クリック →「貼り付け」を選択
5. コピーが完了するまで待つ（ファイル容量によっては数分かかります）

コピー後のフォルダ構成:

```
C:\Tools\ocr_shinseisho\
├── ocr_shinseisho.exe
├── tesseract\
├── config\
└── _internal\
```

### 手順3-4. デスクトップにショートカットを作成（任意）

毎回フォルダを開かなくて済むよう、デスクトップにショートカットを作成します。

1. `C:\Tools\ocr_shinseisho\ocr_shinseisho.exe` を右クリック
2. 「送る」→「デスクトップ（ショートカットを作成）」を選択
3. デスクトップに「ocr_shinseisho - ショートカット」が作成される
4. 必要に応じてショートカットの名前を「OCR申請書読み取りツール」に変更

## 4. 動作確認

### 手順4-1. 初回起動

`C:\Tools\ocr_shinseisho\ocr_shinseisho.exe`（またはデスクトップのショートカット）をダブルクリックします。

### 手順4-2. Windowsセキュリティの警告が出た場合

初回起動時に以下のような警告が表示されることがあります。

**「Windows によってPCが保護されました」（SmartScreen）が表示された場合:**

1. 「詳細情報」をクリック
2. 「実行」ボタンをクリック

> **補足:** この警告はWindowsのセキュリティ機能によるものです。本ツールは安全なソフトウェアですが、配布元の署名証明書がない場合にこの警告が出ます。不明な場合はシステム担当者にご確認ください。

### 手順4-3. 起動確認

アプリが起動したら、以下を確認してください。

**確認1: バージョン表示**
- タイトルバーに `OCR申請書読み取りツール v0.1.0` と表示されること
- 画面右下のステータスバーに `v0.1.0` と表示されること

**確認2: OCRエンジンの状態**

アプリ起動後、画面下部のステータスバーを確認します。

| 表示 | 状態 | 対処 |
|---|---|---|
| `Tesseract: 有効` | ✅ 正常 | そのまま使用可能 |
| `ndlocr-lite: 有効` | ✅ 正常（高精度） | そのまま使用可能 |
| `OCRエンジン: 無効` | ⚠ 要対応 | [手順8](#8-トラブルシューティング) を参照 |

**確認3: テスト処理**

1. 左サイドバーの「OCR処理」をクリック
2. テスト用のサンプルPDFまたは画像ファイルを「ファイル追加」で追加
3. 「OCR処理実行」をクリック
4. 処理が完了し、結果が表示されること

以上で動作確認は完了です。

## 5. ndlocr-liteモデルの追加（任意・高精度化）

ndlocr-liteはTesseractより高精度の日本語OCRエンジンです。縦書きや旧字体の申請書処理精度が向上します。モデルファイルはUSBで転送します。

> **注意:** ndlocr-liteモデルは数百MB〜1GB程度のサイズがあります。16GB以上のUSBメモリを使用してください。

### 手順5-1. モデルファイルの受け取り

システム担当者からUSBメモリで `ndloccr_models` フォルダを受け取ってください。

### 手順5-2. モデルファイルの配置

1. USBメモリの `ndloccr_models` フォルダの中身を、以下のパスにコピーします:

```
コピー先: C:\Tools\ocr_shinseisho\models\ndloccr\
```

2. `models\ndloccr\` フォルダが存在しない場合は作成してください:
   - `C:\Tools\ocr_shinseisho\` を開く
   - `models` フォルダを新規作成
   - `models` フォルダを開いて `ndloccr` フォルダを新規作成

3. USBメモリの `ndloccr_models\` 内のファイルをすべて `C:\Tools\ocr_shinseisho\models\ndloccr\` にコピーします

### 手順5-3. 動作確認

1. アプリを再起動します
2. ステータスバーに `ndlocr-lite: 有効` と表示されれば成功です

## 6. アンインストール方法

本ツールはWindowsのインストーラーを使用していないため、フォルダを削除するだけでアンインストール完了です。

1. アプリが起動中の場合は終了させる
2. `C:\Tools\ocr_shinseisho\` フォルダを削除する
3. デスクトップのショートカットを作成した場合は削除する

> **データについて:** アプリが保存したデータ（様式定義・OCR結果）は `C:\Tools\ocr_shinseisho\` 内に保存されています。フォルダを削除するとデータも削除されます。必要に応じてバックアップを取ってから削除してください。

## 7. アップデート方法

新しいバージョンが配布された場合、以下の手順でアップデートします。

### 手順7-1. 旧バージョンのデータをバックアップ

アップデート前に、様式データと設定をバックアップします。

1. `C:\Tools\ocr_shinseisho\config\` フォルダをデスクトップ等にコピー
2. アプリのDBファイル（`*.db` または `*.sqlite3`）が存在する場合はコピー

### 手順7-2. 旧バージョンの削除

1. アプリを終了させる
2. `C:\Tools\ocr_shinseisho\` フォルダを削除または別名にリネーム（例: `ocr_shinseisho_old`）

### 手順7-3. 新バージョンのインストール

[手順3](#3-インストール手順) と同じ手順で新バージョンをインストールします。

### 手順7-4. データの復元

バックアップした `config\` フォルダを新バージョンのフォルダに上書きコピーします。

## 8. トラブルシューティング

### 起動しない・すぐ終了する

| 現象 | 考えられる原因 | 対処法 |
|---|---|---|
| ダブルクリックしても何も起こらない | 実行権限がない | 管理者権限でPCにログインし直してから試す |
| 画面が一瞬表示されてすぐ消える | 設定ファイルの破損 | `config\` フォルダを削除して再起動（様式データは失われます） |
| 「DLLが見つかりません」エラー | Visual C++ランタイム未インストール | 下記「Visual C++ランタイムのインストール」を参照 |
| 「Pythonが必要です」と表示される | 古いバージョンのexeを使用中 | 最新の配布パッケージに入れ替える |

#### Visual C++ランタイムのインストール

一部のPCでは `vcruntime140.dll` 等が不足している場合があります。

1. システム担当者から `vcredist_x64.exe` をUSBメモリで入手する
2. `vcredist_x64.exe` をダブルクリックしてインストールする
3. インストール完了後、アプリの再起動を試みる

### OCRエンジンが認識されない

**「OCRエンジン: 無効」と表示される場合:**

1. `C:\Tools\ocr_shinseisho\tesseract\tesseract.exe` が存在するか確認する
2. ファイルが存在しない場合は、配布パッケージが不完全です。システム担当者に再配布を依頼してください
3. ファイルが存在する場合は、アプリを再起動してみてください

### Tesseractが日本語を認識しない

`C:\Tools\ocr_shinseisho\tesseract\tessdata\jpn.traineddata` が存在するか確認してください。このファイルが欠けている場合、日本語が認識できません。システム担当者に再配布を依頼してください。

### 「管理者権限が必要です」と表示される

`C:\Program Files\` 以下にインストールされている可能性があります。`C:\Tools\` 以下に移動してください（[手順3-2](#手順3-2-インストール先フォルダの作成) 参照）。

### 処理が非常に遅い

- RAM 4GB未満のPCでは処理が遅くなります
- ndlocr-liteモデルを使用している場合、Tesseractに切り替えると速くなります
- 大量のファイルを一度に処理する場合は、数件ずつ分けて処理してください
