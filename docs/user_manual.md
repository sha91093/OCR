## 1. はじめに

### このツールの目的

「OCR申請書読み取りツール」は、紙の申請書をスキャンした画像やPDFファイルから、記載内容を自動で読み取り、CSV形式のデータとして出力するためのツールです。

これまで目視で行っていた転記作業を自動化することで、入力ミスの削減や業務の効率化を支援します。

### 対象読者

このマニュアルは、LGWAN接続PCでツールを操作する担当者向けに作成しています。パソコンの一般的な操作（マウスのクリック・ドラッグ、ファイルのダブルクリックなど）ができれば、ITの専門知識がなくても操作できます。

### OCRエンジンについて

本ツールは、文字を読み取るための「OCRエンジン」として、以下の2種類に対応しています。

| エンジン名 | 特徴 |
|---|---|
| **ndlocr-lite**（高精度モード） | 国立国会図書館が開発した日本語専用エンジン。縦書きや旧字体を含む申請書に対して高い精度を発揮します。 |
| **Tesseract**（標準モード） | 広く使われているオープンソースのOCRエンジン。ツールに同梱されており、追加インストール不要です。 |

ツールが自動的に利用可能なエンジンを選択します。通常は操作者がエンジンを意識する必要はありません。

## 2. 起動方法

### 2-1. ツールを起動する

デスクトップまたは所定のフォルダにある **`OCR申請書読み取りツール.exe`** をダブルクリックしてください。

> **注意:** Pythonや他のソフトウェアの事前インストールは不要です。exeファイルをダブルクリックするだけで起動できます。

起動すると、以下のような画面が表示されます。

```
+-----------------------------------------------------------+
|  OCR申請書読み取りツール                                    |
+------------+----------------------------------------------+
|            |                                              |
|  OCR       |                                              |
|  申請書    |   メインコンテンツエリア                      |
|  読み取り  |                                              |
|            |                                              |
|  様式管理  |                                              |
|  OCR処理   |                                              |
|  結果確認  |                                              |
|  設定      |                                              |
|            |                                              |
|  v1.0.0    |                                              |
+------------+----------------------------------------------+
|  ステータスバー（操作状況がここに表示されます）              |
+-----------------------------------------------------------+
```

### 2-2. 画面の構成

画面は大きく3つのエリアで構成されています。

- **左サイドバー（濃い紺色の部分）:** 操作したい機能を選ぶメニューです。「様式管理」「OCR処理」「結果確認」「設定」の4つのボタンがあります。クリックすると右側のコンテンツエリアが切り替わります。
- **メインコンテンツエリア（右側の広い部分）:** 選んだ機能の操作画面が表示されます。
- **ステータスバー（画面最下部）:** 現在の処理状況やメッセージが表示されます。何か操作したときはここを確認してください。

### 2-3. バージョンを確認する

画面左下のサイドバーに **`v1.0.0`** のようにバージョン番号が表示されています。問い合わせの際にはこのバージョン番号をお伝えください。

### 2-4. OCRエンジンの状態を確認する

画面右下のステータスバーに **`DB: 接続済み`** と表示されていれば、ツールは正常に動作しています。

**`DB: デモモード`** と表示されている場合は、データの保存機能が制限されています。この状態ではOCR処理は行えますが、結果が次回起動時に引き継がれません。システム担当者にご連絡ください。

## 3. 様式の登録

OCR処理を行うには、まず「どの申請書のどの位置に何が書かれているか」をツールに教える必要があります。この設定を「様式」と呼びます。

### 3-1. 様式管理画面を開く

左サイドバーの **「様式管理」** をクリックしてください。

画面は左右に分かれており、左側に「様式一覧」、右側に「様式詳細・フィールド定義」が表示されます。

### 3-2. 新しい様式を作成する

1. 様式一覧エリアの **「新規作成」** ボタンをクリックします。
2. 様式名の入力を求めるダイアログが表示されます。申請書の名前（例：「住民票申請書」「転入届」）を入力して **「OK」** をクリックします。
3. 一覧に新しい様式が追加されます。

### 3-3. 読み取り領域（フィールド）を定義する

様式を作成したら、「どこを読み取るか」を定義します。この定義の単位を「フィールド」と呼びます。

#### テンプレート画像を使って領域を設定する（推奨）

申請書のひな形（PDF または画像ファイル）を使って、マウスで読み取り領域を指定できます。

1. 様式一覧から対象の様式をクリックして選択します。
2. 右側のボタンエリアにある **「テンプレート画像で領域設定」** をクリックします。
3. ファイル選択ダイアログが開くので、申請書のひな形ファイル（PDF・PNG・JPEG・TIFF・BMPに対応）を選択して開きます。
4. 申請書の画像が表示されます。読み取りたい箇所をマウスでドラッグして矩形（四角形）に選択してください。
5. ドラッグを放すと、ラベル入力のダイアログが表示されます。そのフィールドの名前（例：「氏名」「住所」「生年月日」）を入力して **「OK」** をクリックします。
6. 必要なすべての項目について手順 4〜5 を繰り返します。
7. 完了したら **「保存」** をクリックします。

> **ヒント:** 選択した領域が青い枠で表示されます。ドラッグが難しい場合は、画像を少し拡大してから操作してください。

#### 手動でフィールドを追加する

座標値を直接入力してフィールドを追加することもできます。

1. **「フィールド追加」** ボタンをクリックします。
2. フィールド編集ダイアログが表示されます。以下の項目を入力します。

   | 項目 | 説明 |
   |---|---|
   | フィールド識別名 | 半角英数字で入力します（例：`name`、`address`）。CSV出力時の列名になります。 |
   | 表示ラベル | 日本語で入力できます（例：「氏名」「住所」）。画面上での表示に使われます。 |
   | ページ番号 | 複数ページのPDFの場合、何ページ目かを指定します。1ページのみの場合は「1」のままでかまいません。 |
   | 座標 X1・Y1・X2・Y2 | 読み取り領域の左上(X1,Y1)と右下(X2,Y2)の座標をピクセル単位で入力します。 |
   | フィールド種別 | 「text（文字）」「number（数値）」「date（日付）」から選択します。 |

3. 入力が完了したら **「OK」** をクリックします。

### 3-4. 様式情報を保存する

フィールドの定義が終わったら、右側パネルの **「保存」** ボタンをクリックします。「様式を保存しました。」というメッセージが表示されれば完了です。

> **注意:** 「保存」をクリックしないと、変更内容が失われます。忘れずに保存してください。

### 3-5. 様式を削除する

不要になった様式は削除できます。

1. 様式一覧から削除したい様式を選択します。
2. **「削除」** ボタンをクリックします。
3. 確認メッセージが表示されます。**「はい」** をクリックすると削除されます。

> **注意:** 様式を削除すると、その様式に関連するフィールド定義とOCR処理済みの結果もすべて削除されます。削除前に必要なデータをCSVに出力しておいてください。

## 4. OCR処理の実行

登録した様式を使って、申請書ファイルの文字を読み取ります。

### 4-1. OCR処理画面を開く

左サイドバーの **「OCR処理」** をクリックしてください。

画面は上から「処理設定」「処理実行」「CSV出力」の3つのエリアに分かれています。

### 4-2. 様式を選択する

「処理設定」エリアの **「使用する様式」** のプルダウンメニューをクリックし、処理したい申請書に対応する様式を選択します。

> **ヒント:** プルダウンに様式が表示されない場合は、右の **「更新」** ボタンをクリックしてみてください。

### 4-3. 処理するファイルを選択する

1. **「ファイル追加」** ボタンをクリックします。
2. ファイル選択ダイアログが開きます。処理したい申請書のファイルを選択して **「開く」** をクリックします。

   - 対応形式: PDF、PNG、JPEG、TIFF、BMP
   - **Ctrlキーを押しながらクリック**すると、複数のファイルを一度に選択できます。

3. 選択したファイルの名前が「処理ファイル」の一覧に追加されます。
4. ファイルを追加し直したい場合は、**「一覧クリア」** ボタンで一覧を空にしてから、再度追加してください。一覧の中から特定のファイルだけ外したい場合は、そのファイルをクリックして選択し、キーボードの **Deleteキー** を押してください。

### 4-4. OCR処理を開始する

**「OCR処理実行」** ボタンをクリックしてください。

処理が開始されると以下のように変化します。

- **「OCR処理実行」** ボタンが操作できなくなります（処理中は押せません）。
- **「中止」** ボタンが操作できるようになります。
- 画面中央のプログレスバーが進み、処理の進捗が表示されます（例：「1/3」「2/3」）。
- 処理ログエリアに、各ファイルの処理状況がリアルタイムで表示されます。

### 4-5. 処理の完了を確認する

処理が完了すると、ログエリアに「処理完了: 成功 3件 / エラー 0件 (12.5秒)」のような集計メッセージが表示されます。

プログレスバーが100%になり、「CSV出力」ボタンが操作できるようになれば、OCR処理は完了です。

### 4-6. 処理を途中で中止する

処理中に **「中止」** ボタンをクリックすると確認ダイアログが表示されます。**「はい」** を選ぶと処理が停止します。

> **注意:** 中止した場合でも、中止するまでに処理が完了したファイルの結果は保存されています。

## 5. 結果の確認とCSV出力

OCR処理が終わったら、認識結果を確認し、必要に応じて修正してからCSVファイルとして出力します。

### 5-1. 結果確認画面を開く

左サイドバーの **「結果確認」** をクリックしてください。

画面上部で様式を選ぶと、その様式で処理した結果の一覧が表示されます。

### 5-2. 結果の一覧を確認する

画面左側の「OCR結果一覧」に、処理したファイルの一覧が表示されます。各行に以下の情報が表示されます。

| 列名 | 説明 |
|---|---|
| ファイル名 | 処理したファイルの名前 |
| 処理日時 | OCR処理を実行した日時 |
| ステータス | `success`（成功）、`partial`（一部認識失敗、橙色表示）、`error`（失敗、赤色表示） |
| フィールド数 | 認識されたフィールドの数 |

### 5-3. 認識結果を詳細確認する

一覧の行をクリックすると、画面右側の「詳細表示・修正」エリアに選択したファイルの詳細情報が表示されます。

各フィールドについて、認識されたテキストと**信頼度（%）**が表示されます。

- **緑色（80%以上）:** 高い精度で認識できています。
- **オレンジ色（50〜79%）:** やや精度が低い可能性があります。内容を確認してください。
- **赤色（50%未満）:** 認識精度が低い状態です。必ず目視で確認し、修正してください。

### 5-4. 認識テキストを修正する

認識結果に誤りがある場合は、直接修正できます。

1. 詳細表示エリアで、修正したいフィールドの入力欄をクリックします。
2. テキストを直接編集します（不要な文字の削除、正しい文字の入力など）。
3. すべての修正が終わったら、**「変更を保存」** ボタンをクリックします。

> **ヒント:** 修正した内容は、後でCSVに出力する際に反映されます。

### 5-5. CSVファイルに出力する

#### 選択した件数のみ出力する

1. 一覧から出力したいファイルの行をクリックして選択します。複数選択するには、**Ctrlキーを押しながらクリック**します。すべて選択する場合は **「全選択」** ボタンを使ってください。
2. 画面上部の **「選択件 CSV出力」** ボタンをクリックします。

#### すべての結果をまとめて出力する

画面上部の **「全件 CSV出力」** ボタンをクリックします。

#### 保存先と文字コードの設定

「CSV出力」ボタンをクリックすると、ファイルの保存先を選ぶダイアログが表示されます。

保存先を選んで **「保存」** をクリックすると、CSVファイルが出力されます。

> **ヒント:** 出力されるCSVファイルの文字コードは **BOM付きUTF-8（utf-8-sig）** です。このファイルはExcelでそのまま開いても文字化けしません。

#### CSVの内容

出力されるCSVには以下の列が含まれます。

| 列名 | 内容 |
|---|---|
| ファイル名 | 処理したファイルの名前 |
| 処理日時 | OCR処理を行った日時 |
| ステータス | 処理の状態（success / partial / error） |
| （フィールド名） | 各フィールドの認識テキスト（様式に定義した項目数だけ列が増えます） |

## 6. よくある質問

**Q1. 起動しようとしたら「WindowsによってPCが保護されました」という画面が出てきた。どうすればいいですか？**

A. このメッセージはWindowsのセキュリティ機能（SmartScreen）が表示しているものです。ツールをインストールした後、初めて起動するときに表示されることがあります。「詳細情報」をクリックしてから「実行」をクリックすると起動できます。不安な場合はシステム担当者にご確認ください。

---

**Q2. ファイルを追加しようとしたが、目的のファイルが選択できない（グレーアウトされている）。**

A. 本ツールが対応しているファイル形式は PDF、PNG、JPEG（JPG）、TIFF（TIF）、BMP です。これ以外の形式（例：Wordファイル、Excelファイルなど）は直接読み込めません。対応形式に変換してからお試しください。また、ファイルダイアログで「ファイルの種類」を「すべてのファイル」に変更すると選択できる場合もあります。

---

**Q3. OCR処理は完了したが、認識結果がほぼすべて空欄になっている。**

A. 以下の原因が考えられます。

- **様式のフィールド定義が合っていない:** 使用した様式のフィールド座標が、実際の申請書の記載位置とずれている可能性があります。「様式管理」画面でフィールドの定義を確認・修正してください。
- **画像の解像度が低い:** スキャン画像の解像度が粗すぎると認識精度が下がります。300dpi以上でスキャンしていただくと精度が向上します。
- **OCRエンジンが「モック」状態になっている:** ステータスバーに「OCRエンジン: mock」と表示されている場合、エンジンが正常に動作していません。ツールを再起動してみてください。それでも改善しない場合はシステム担当者にご連絡ください。

---

**Q4. 処理が終わった後、「結果確認」画面に結果が表示されない。**

A. 「結果確認」画面上部の様式プルダウンで、OCR処理を行った様式が選択されているか確認してください。様式が正しく選択されている場合は、**「更新」** ボタンをクリックして一覧を再読み込みしてみてください。

---

**Q5. 出力したCSVファイルをExcelで開いたら文字が「????」のように表示されて文字化けした。**

A. CSVファイルをExcelで直接ダブルクリックして開くと、稀に文字化けが起きることがあります。以下の手順でExcelから開いてください。

1. Excelを起動します。
2. 「データ」タブ→「テキストまたはCSVから」を選択します。
3. 出力したCSVファイルを選択します。
4. プレビューが表示されたら、「ファイルの発信元」が「65001: Unicode (UTF-8)」になっていることを確認して「読み込み」をクリックします。

または、別の方法として「OCR処理」画面の「CSV出力」エリアで、「文字コード」を **`shift_jis`** に変更してから出力し直すとExcelでそのまま開ける場合があります。

---

**Q6. ツールの動作が重く、処理に非常に時間がかかる。**

A. 以下をお試しください。

- 一度に処理するファイル数を減らしてください（1〜2ファイルずつ処理する）。
- 画像ファイルの解像度が極端に高い（600dpi以上など）場合、処理前に解像度を下げてください。
- 他のアプリケーションをすべて閉じてから処理を実行してください。
- OCR処理中はPCをスリープモードにしないよう注意してください。

---

**Q7. 「様式管理」画面で「テンプレート画像で領域設定」ボタンが灰色になっていて押せない。**

A. 領域設定機能に必要なモジュールが読み込めていない状態です。ツールを一度閉じて再起動してみてください。それでも改善しない場合はシステム担当者にご連絡ください。この場合は「フィールド追加」ボタンから手動で座標を入力してフィールドを定義することができます。

---

## 7. エラーが出たときは

### エラー: 「様式一覧の読み込みに失敗しました」

**原因:** ツールのデータベースファイルへのアクセスに失敗しています。

**対処法:**
1. ツールを一度終了し、再起動してください。
2. 再起動後も同じエラーが出る場合は、以下のフォルダにデータベースファイル（`ocr_shinseisho.db`）が存在するか確認してください。
   - `C:\Users\（ユーザー名）\.ocr_shinseisho\`
3. 上記フォルダが存在しない、またはファイルが壊れている場合は、システム担当者にご連絡ください。

---

### エラー: 「フィールドが設定されていません」

**原因:** 選択した様式に読み取り領域（フィールド）が1つも定義されていません。

**対処法:** 「様式管理」画面を開き、対象の様式を選択して、フィールドを定義してから再度OCR処理を実行してください。フィールドの登録手順は [3. 様式の登録](#3-様式の登録) を参照してください。

---

### エラー: 「出力フォルダを作成できません」

**原因:** CSVの出力先として指定したフォルダへの書き込み権限がないか、ドライブのパスが見つかりません。

**対処法:**
1. 「CSV出力」エリアの「出力フォルダ」欄に設定されているパスを確認してください。
2. **「参照...」** ボタンをクリックして、デスクトップや「ドキュメント」フォルダなど、書き込み可能な別の場所を選択してください。

---

### エラー: 「OCR処理が既に実行中です」

**原因:** 前の処理がまだ完了していない状態で「OCR処理実行」ボタンを再度押しました。

**対処法:** 現在の処理が完了するまでお待ちください。処理を中止したい場合は **「中止」** ボタンをクリックしてください。

---

### エラー: 「処理するファイルを追加してください」

**原因:** ファイルが1件も追加されていない状態で「OCR処理実行」ボタンを押しました。

**対処法:** 「ファイル追加」ボタンから処理対象のファイルを追加してから、再度「OCR処理実行」ボタンをクリックしてください。

---

### エラー: 「様式を選択してください」

**原因:** 「OCR処理」画面で様式が選択されていない状態で「OCR処理実行」ボタンを押しました。

**対処法:** 「使用する様式」プルダウンメニューから適切な様式を選択してから、再度「OCR処理実行」ボタンをクリックしてください。プルダウンに様式が表示されない場合は「更新」ボタンを押してから再度選択してください。

---

### エラー: 処理ログに「エラー: （ファイル名） - ...」と表示された

**原因:** 特定のファイルのOCR処理中に問題が発生しました。

**対処法:**
1. 他のファイルの処理は続行されます。エラーが出たファイルだけ再処理を試みてください。
2. エラーの内容によっては、ファイルが壊れているか、対応していない形式の可能性があります。ファイルを別の形式（例：PDFをPNG画像に変換）で保存し直してから再試行してください。
3. 繰り返しエラーが発生する場合は、エラーメッセージ全文をメモしてシステム担当者にご連絡ください。

---

### それでも解決しない場合

上記の対処法で解決しない場合は、以下の情報をシステム担当者にお伝えください。

- ツールのバージョン（画面左下に表示）
- 操作の手順（何をしようとしたときにエラーが出たか）
- エラーメッセージの内容（可能であればスクリーンショット）
- 処理しようとしたファイルの形式とおおよそのファイルサイズ
